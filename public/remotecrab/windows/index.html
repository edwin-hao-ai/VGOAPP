「未知发布者」是什么意思

代码签名证书要每年购买，我们还没买。所以 Windows 看到的是一个可执行文件，但不知道是谁做的 —— 它就把这件事如实告诉你。

这不是"发现病毒"的提示。真实的病毒拦截长这样：红色的全屏页，只有一个「不运行」。

为什么会问你两次

第一次是 UAC：安装程序要写入 C:\Program Files，需要管理员权限。这是 Windows 自己的规则，任何安装程序都会问。

第二次……其实没有第二次。按上面的顺序做，只有这一个提示。

常见问题

还是弹了「Windows 已保护你的电脑」怎么办？

说明第 2 步（解除锁定）漏掉了，或者你是直接双击了里面的 exe。点「更多信息」→「仍要运行」也能继续，但更省事的做法是回到第 2 步重新解压一次。

install.cmd 是干什么的？我能看看吗？

能，用记事本打开就是纯文本。它只做三件事：解除当前文件夹里所有文件的锁定、用 msiexec 静默安装、启动 RemoteCrab。没有联网、没有下载、没有别的动作。

连不上手机？

先确认电脑和手机在同一个 Wi-Fi、手机上的 App 是打开的。第一次连接手机会弹出配对请求，点「允许」。如果公司网络隔离了设备之间的通信，可以先用手机热点试一次。

怎么卸载？

设置 → 应用 → 已安装的应用 → RemoteCrab → 卸载。虚拟摄像头会一起移除；如果你在托盘里手动安装过它，卸载程序也会清理注册表项。

为什么官网写的是「不过商店」？

因为它需要安装一个虚拟摄像头和一个后台服务，这两样都不能通过 Microsoft Store 的沙箱发布。直接下载是唯一能保留全部功能的方式。
