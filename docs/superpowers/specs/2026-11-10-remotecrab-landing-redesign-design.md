# RemoteCrab 官网改版 — 设计

日期：2026-11-10
原型：`prototypes/remotecrab-redesign/index.html`（zh / en 双语，真机片段）

## 为什么要改

不是"不好看"，是两件具体的事：

1. **转化**：首屏 900px 没有产品画面；系统要求写"macOS 26+ / iOS 26+"（商店写的是 17.0），写在 CTA 下面 12px 灰字里；14 个功能平铺成 13 张等权卡片且"订阅"排第一；全站没有一个 `<video>`，而 36–50 MB 的成片已经做好了；安装要动辅助功能、相机扩展、音频驱动，页面只有一句"按引导授权"；没有回答"为什么不用 Continuity Camera"，而 macOS 26 用户 100% 有它。
2. **曝光**：`/en/` 的 `<title>`/`og` 全是中文且正文未预渲染（3.9 KB 空壳）；14 个功能页里 6 个预渲染失败（3 KB 空壳），正好是 camera / trackpad / voice / ai / speaker / automation；`og:image` 指向 1024×1024 方图标，而 `dist/og-image.png` 有现成的 1200×630 没用上；sitemap 只有产品页，没有内容层。

## 目标 / 非目标

**目标**

- 能装的人在 30 秒内知道"这是什么、我这台能不能装、现在点哪个"。
- 14 个落地页恢复可被抓取，英文站变成真的英文站。
- 功能不丢：20 组、14 组带页、6 组补页。

**非目标**

- 不改产品、不改订阅价格（$3.99/月 · $29.99/年 不变）。
- 不换品牌视觉、不重做设计系统（沿用 VGO 深色 + 紫蓝渐变）。
- 不改 14 个落地页的正文结构（hero / problem / how / details / tips / requires / next）。

## 约束

- 站点是 Vite + React 多页 + `scripts/prerender.sh` 预渲染，`scripts/i18n-routes.py` 生成 `/en/` 镜像。
- 视频是 1080×1920 竖片、带烧字，语言写死在画面里，所以每语言一套。
- 原始成片 36–50 MB，不能直接上网页。
- macOS 26 的声明出现在 14 个落地页 × 3 条 `requires`，降支持范围是一次跨页面的文案改动。

## 决策

1. **首屏视频用 4:5「海报 stage」**：模糊底色取同一帧，9:16 原片居中、不裁切。
   理由：9:16 在 1200px 版心里是一条瘦高块，旁边只能放 200px 高的文字；裁成 16:9 会切掉烧字和画面里的手机。
2. **首屏只留一个主 CTA**，按 UA 切 Mac / Windows；App Store 一个次按钮；**移除 TestFlight**（正式产品上的"公测"伤信任）。
3. **首屏视频用最新 34 秒讲解片**（`film-long-zh/renders/long-zh.mp4`，2026-11-10 19:21），**从 4.2s 起播** —— 片头 4 秒是一张写着同一句「一部手机 补全你的电脑」的标题卡，和 H1 重复。
4. **功能清单按 14 个落地页组织**（20 组，14 组可点进页面），子功能用「含 …」表达，不新造一套命名。
5. **新增「和系统自带的关系」对比表**：Continuity Camera / Sidecar 逐条对照，正面回答最大反驳。
6. **价格上首页**：免费永久 vs $3.99/月；「订阅」不再是功能列表第一张卡。
7. **新增「装的时候会弹出这些」四步**：Gatekeeper → 辅助功能 → 相机扩展（管理员密码）→ 手机配对，每条给原因和路径。
8. **4 个场景行改成横带**：左 320 画框 + 右文案 + 3 条要点 + 落地页链接；片段用 22:2x 那批 12 秒片。
9. **视频流水线**：每条片出 720p / 无音 / CRF 31 / faststart 的 web 版 + 首帧 poster，按语言各一套；首屏预加载，其余视口内播放。
